# 🏠 House Price Predictor

A Machine Learning project that predicts house prices using Linear Regression!

## 📌 Features
- 🤖 Linear Regression model with 97% accuracy
- 🏠 Predicts house price based on 8 features
- 📊 Model evaluation with MAE and R2 score

## 🛠️ Tools Used
- Python 3.12
- Pandas
- NumPy
- Scikit-learn

## 📊 Model Performance
- R2 Score: 0.97 (97% accurate!)
- Mean Absolute Error: $10,432

## 🔍 Features Used
- Overall Quality
- Living Area
- Garage Capacity
- Basement Area
- Year Built
- Number of Bathrooms
- Number of Bedrooms
- Lot Area

## 🚀 How to Run
1. Clone the repository
2. Install dependencies: `pip install pandas numpy scikit-learn`
3. Add `house_prices_practice.csv` in the same folder
4. Run: `python predictor.py`
5. Enter house details and get predicted price!
